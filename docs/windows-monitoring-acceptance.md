## 构建与安装

在 Windows 10/11 开发机安装 Node、pnpm、Rust MSVC、Visual Studio C++ Build Tools、Windows SDK 和 WebView2。

```powershell
pnpm install --frozen-lockfile
pnpm test
pnpm build
cargo test --manifest-path src-tauri/monitor-core/Cargo.toml
cargo check --manifest-path src-tauri/Cargo.toml
pnpm desktop:build
```

安装 `src-tauri/target/release/bundle/nsis` 中的 `.exe` 或 `msi` 中的 `.msi`。记录 Windows 版本、显示器布局、缩放比例和应用版本。安装包未签名时，按部署环境的正常安装政策处理。

## 数据位置

点击 logo 10 次并通过密码验证后，通过“监控设置”弹窗中的“打开记录目录”获取实际路径。日期文件夹中的 `captures.jsonl` 与 JPEG 一一核对，不再创建或追加 `events.jsonl`。Windows 日志查看“事件查看器 → Windows 日志 → 系统”，按来源 `SecurityMonitoring` 筛选。

旧版本将应用日志源注册在 Application（应用程序）中。升级后需在设置里重新点击“注册日志源”并允许 UAC；使用新的系统日志源，避免复用旧来源时受 Windows 日志映射缓存影响。旧的应用程序日志及来源不删除。未注册系统日志源时明确报错，不回退写入 Application。微软说明：将同一个来源重新关联到另一日志需要重启系统，参见 [CreateEventSource](https://learn.microsoft.com/en-us/dotnet/api/system.diagnostics.eventlog.createeventsource)。

没有 Windows 服务；未登录用户、休眠或关机期间不采集屏幕。本地记录目前为 JPEG 和 JSONL，不代表防篡改审计存储。

## 日志字段与文件核对

新截图的 `md5` 为写入 JPEG 文件的完整字节的 MD5，使用 32 位小写十六进制，同时记录于 `captures.jsonl` 和截图成功事件。旧索引缺少该字段时读取为 `null`，不回写虚构校验值。校验及保存耗时包括 MD5 计算、图片落盘和索引落盘；采集及编码耗时包括桌面检查、采集、JPEG 编码及前台信息读取。记录时间是生成存储记录的时间，事件时间是写入日志的时间。

在 Windows 上将路径替换为日志中的完整图片路径，核对结果与日志和索引的 MD5 一致（忽略大小写）：

```powershell
Get-FileHash -LiteralPath 'D:\监控记录\2026-10-13\实际截图文件.jpg' -Algorithm MD5
```

事件 ID：1000 注册日志源，1001 启动，1002 正常退出，1003 开始监控，1004 停止监控，1005 配置修改或日志源注册完成，1100 截图成功，1101 截图失败，1102 暂停，1103 恢复，1200 自动删除，1201 清理失败，1999 其他客户端错误。失败事件使用错误级别，其余为信息；正常锁屏暂停不标成故障。每条客户端事件附带版本、进程 ID、运行批次、用户和 Windows 会话 ID；注册时由 PowerShell 写入的 1000 事件除外。

配置修改记录修改前后的生效值；删除日志仅在文件实际删除后写成功，索引后续更新失败另报清理错误。窗口标题仍保留在截图索引中，默认不写入系统日志。
